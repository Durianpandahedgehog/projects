# Loan Default Risk Model - Heritage Credit Union
**By Aisha Nomani, Sai Han Shan Pha, Luis Alay Guerrero (Fernando), Aurelia Vo, and An Chu**

Developed a cost-sensitive binary classification model to assess loan default risk using historical borrower data. Conducted exploratory data analysis and feature engineering to identify key risk drivers, then trained and compared multiple models including logistic regression, random forest, SVM, and XGBoost using stratified cross-validation. Optimized the classification threshold based on business cost trade-offs (FN vs. FP) to minimize total financial loss and align with underwriting capacity. On the held-out test set (999 applications), the cost-optimal threshold of 0.32 cut total misclassification cost by 27%, from $772,800 to $560,800, compared with the default 0.50 threshold. The final model supports risk-based loan review decisions.
